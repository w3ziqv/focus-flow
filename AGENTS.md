# Focus Flow project instructions

## Language

- Write developer-facing project material in English: commit messages, pull request titles and descriptions, issues, documentation, release notes, code comments, test names, assertion messages, and validation reports.
- Keep the application's supported languages and localized UI copy. Preserve translated strings and fixtures or selectors that intentionally test a particular locale.
- Communicate with the maintainer in Polish unless another language is requested. The conversation language does not change the project's documentation language.

## Copy

- Use the `humanizer` skill for authored or revised prose, including application copy, guides, and project documentation.
- Keep factual claims and research limitations intact. Do not add unsupported benefits, statistics, or citations while editing the wording.
